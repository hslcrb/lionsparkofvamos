# 삼성 라이온즈 팬 응원 메인 기획

작성일: 2026-11-03. 상태: 기획안. 이 문서의 신규 기능은 아직 구현하거나 배포하지 않았다.

## 목적과 범위

경기 전에는 일정과 시청 경로를 찾고, 경기 중에는 서로의 응원을 보고, 경기 후에는 공식 영상과 응원가로 돌아올 수 있는 비공식 팬 공간을 만든다. 삼성 라이온즈의 파랑, 기존 로고와 이사만루체를 바탕으로 실제 구단 응원에서 출발한다. 추상적인 감성 문구, 근거 없는 승리 선언, 반복되는 영어 장식은 쓰지 않는다. 응원관은 차후 Blender로 공간을 제작하되 이번에는 공간의 요구사항만 기록한다. 라팍월드에는 손대지 않는다.

## 화면 구성

1. **첫 화면**: 기존 로고와 응원 버튼을 중심에 두고, 구단 공식 응원가에서 확인한 짧은 구호를 이사만루 Bold로 배치한다. 매 영역에 같은 구호를 반복하지 않고, 기능 설명은 ‘응원 보내기’처럼 직접 쓴다.
2. **경기·시청 정보**: 가장 가까운 삼성 경기의 상대, 한국 시간, 장소, 경기 상태와 공식 일정 링크를 보여준다. 포스트시즌 및 CGV 한국시리즈 생중계가 공식 발표되면 별도 항목에 극장·시각·상태·예매 링크를 표시한다. 미발표, 순연, 취소, 매진, 확인 불가를 구분하고 확인 시각과 출처를 함께 둔다. 경기 편성과 극장 상영 편성은 서로 다른 데이터로 취급한다.
3. **함께 응원**: 기존 응원 수와 접속 상태를 유지하고, 댓글 작성·신고와 최근 댓글 목록을 제공한다. 승인된 댓글이 제한된 별도 영역을 지나갈 수 있으며 표시를 일시정지하거나 움직임을 끌 수 있다. 글을 놓친 사람은 정적 목록에서 다시 읽는다.
4. **공식 영상과 응원가**: 구단·KBO·공식 권리자의 영상과 사이트를 명확히 표시하고 외부 링크를 제공한다. 삽입이 허용된 YouTube 영상만 선택적으로 표시하며 중계 자체를 이 사이트가 제공하는 것처럼 표현하지 않는다. 음악 항목에는 ‘나의 라이온즈’ 외에 ‘치고 달려라’ 등 사용자가 요청한 곡을 후보로 기록하고, 공식 명칭과 권리·재생 가능 여부를 확인한 뒤 공개한다. 이용할 수 없을 때는 공식 출처 링크를 우선한다.
5. **팬사이트 표기**: 비공식·비상업적 팬 프로젝트임을 눈에 띄되 간결하게 밝히고, 구단·KBO·CGV의 공식 서비스로 오인되지 않도록 한다. 권리와 출처는 실제 이용 조건에 맞춰 별도 안내한다.

## 화면과 상호작용의 기준

- 삼성 블루와 기존 팀 자산을 우선하고 이사만루체 300·400·700을 제목과 정보의 위계에 맞게 쓴다. 글꼴을 불러오지 못하면 읽을 수 있는 한글 대체 글꼴을 사용한다.
- 모바일 320·390·768px 및 데스크톱에서 제목, 경기 상태, 댓글 입력, 음악 조작, 공식 링크가 잘리지 않고 손가락과 키보드로 사용 가능해야 한다. 가로 스크롤로 내용을 숨기지 않는다.
- 응원 수·댓글과 영상 플레이어는 각각 독립된 영역이다. 댓글을 YouTube 영상, 컨트롤, 광고 또는 출처 위에 겹치지 않는다. YouTube 플레이어는 공식 최소 크기를 지키고 삽입 실패 시 원본 영상 링크를 제공한다.
- `prefers-reduced-motion`을 존중하고 움직이는 댓글의 일시정지·정적 대안을 제공한다. 스크린리더에 모든 댓글을 자동 낭독하지 않고 사용자가 최근 목록을 확인할 수 있도록 한다.
- 음악은 사용자의 명시적인 조작을 따르고 기존 소리 켜기·끄기와 낮은 음량 설정을 유지한다. 자동재생이 차단되면 조작 가능한 상태를 보여준다.

## 데이터 연동과 권리

- KBO의 경기 일정과 CGV의 극장 편성은 공식 페이지 및 이용 조건을 우선한다. 공개 API나 계약된 피드가 있는지는 별도 확인 대상이며, 존재하거나 자유롭게 수집할 수 있다고 가정하지 않는다. 허용된 자동 제공 경로가 없으면 공식 링크와 검수된 수동 등록을 사용한다.
- 각 편성에는 `sourceUrl`, `checkedAt`, 한국 시간대와 상태를 저장한다. 마지막 확인 정보가 오래되거나 조회에 실패하면 그 사실을 표시하고 원본으로 이동시킨다. 임의로 경기 일시나 상영관을 만들지 않는다.
- 임베드는 영상별 허용 여부와 플랫폼 정책을 따르며 재생 불가·지역 제한·삭제를 처리한다. 유튜브 원본 플레이어와 광고·출처를 가리지 않는다.
- 음원·영상·로고·사진의 사용 범위는 권리자와 제공처 조건을 확인한다. 비상업적 목적이나 팬사이트 고지만으로 음악 또는 영상 사용 권한이 생기지는 않는다. 허락된 음원이나 공식 삽입·링크를 우선하고, 자체 호스팅은 별도 권리 확인 후 결정한다.

## 실시간 응원과 댓글

현재 `/api/room`은 단일 `cinema` Durable Object에 연결하며 WebSocket hibernation을 사용한다. 응원마다 카운트를 저장하고 연결된 소켓 전체에 보내므로, 경기 중 대규모 동시 접속에서는 쓰기와 전송이 한 객체에 집중될 수 있다. 현재 댓글, 신고, 운영자 도구는 없다.

향후 연결은 초기 스냅샷(응원 수·최근 댓글·접속 상태), 이벤트 ID와 순서, 중복 방지, 연결 끊김 표시 및 재동기화를 정의한다. 재연결은 지수 백오프와 무작위 지연으로 분산한다. 응원 이벤트와 접속자 수는 짧은 단위로 묶어 전송하는 방안을 먼저 측정한다. 한 방으로 부족하다는 근거가 생기면 경기 ID와 샤드 단위로 분산하고, 전역 합계의 정확도·표시 지연·샤드 간 순서 차이를 별도로 명시한다. 저장 전에 확인된 응원이 재시도 중 중복 반영되지 않도록 멱등성을 검증한다.

댓글은 서버에서 길이·빈도·형식을 검증하고 HTML을 실행하지 않는 텍스트로 표시한다. 신고, 숨김, 운영자 검토, 스팸 제한과 최소한의 개인정보 수집을 설계한다. 보관 기간, 삭제 요청 및 운영 담당자는 서비스 공개 전에 정하고 공개한다. 지나가는 댓글은 동시 표시량을 제한하고 이벤트가 많을 때 샘플링하되, 정적 목록·신고 대상과 화면 표시의 관계를 명확히 한다.

## 향후 VAMOS 응원관: 문서만

기존 응원관과 별도로, Blender MCP를 이용해 실제 공간감을 가진 삼성 응원관을 차후 제작한다. 로고, 좌석과 스크린, 조명, 시점·이동 조작, 모바일 성능과 접근성을 설계한다. 실시간 응원과 영상이 있다면 공간 객체·네트워크·미디어를 분리하고, 모델의 소유권·출처와 경량화·충돌·브라우저 호환성을 확인한다. 외부 영상은 재생·표시 조건을 확인하기 전까지 공간 스크린에 넣지 않는다. 이 단계에서는 모델 파일, 공간 구현 또는 배포를 만들지 않는다.
