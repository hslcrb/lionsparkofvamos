# Lions blue / clear acrylic

## Identity

The supplied Lions and VAMOS SVGs stay intact. The supplied Lions mark contains #0066B2, white and silver; those colors define the interface. The team mark and the shared act of cheering remain the center of the page. The header uses the Lions mark rather than an unrelated symbol. The entry screen retains only the two original destinations and paired logos.

Official context reviewed: [club emblems](https://www.samsunglions.com/intro/intro04.asp) and [club history](https://www.samsunglions.com/intro/history_3_4.asp). No historical or current-performance claims have been added to the product.

## Reference interpretation

The supplied water image informs the clarity of light and cool blue values; no flowers or copied background are used. The acrylic reference informs edge thickness, reflection and transmission, without its unrelated brand or typography. The fluted-glass examples inform a restrained vertical light field. Their pink, violet, orange and neon accents are not adopted.

The cheer button has a physical transparent Three.js shell (transmission, thickness, IOR and a generated studio environment). A separate blue foreground preserves the silver/white emblem's readability without distorting the logo. A readable blue emblem remains when WebGL is unavailable. Panels use thin reflected edges, quiet contact shadows and transparent white surfaces. All product text stays readable.

## Motion and operation

Ambient light drifts slowly; the acrylic shell floats and responds to a fine pointer. A main-page motion control pauses ambient CSS and WebGL motion. Reduced-motion preferences remove continuous movement. The renderer caps pixel ratio and frame rate, skips hidden/offscreen work, skips repeated static draws, and disposes its resources.

Existing cheer counts, dance sharing, music gain/fade, routing and HTTP 404/418 behavior remain in use. GitHub Actions is archived as check.yml.txt. Cloudflare production builds run npm run check before Wrangler deployment from main.
