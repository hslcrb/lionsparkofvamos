# 대구 라팍 v6 · WIN OR WOW — 배포 · 지적 · 지형 기록

라팍 오브 바모스 **v6**는 3D 모델 자체를 다시 세운 버전입니다. 이 문서는 모델에 반영한
수치와 그 근거, 그리고 바뀐 좌표계를 기록합니다.

## 1. 필드 축 — 동북동(ENE) 67.5°

- 홈플레이트 → 센터 펜스 방향을 **동북동(67.5°)** 으로 두었습니다.
- 근거: "새 야구장의 중심축(투수와 포수를 기준으로 한 축)은 동북동 방향이다. 경기가 진행될 때
  관람객이 햇빛을 등질 수 있게 설계한 것이다. 이곳의 홈팀 관람석은 오후 4시쯤부터 전 좌석에
  그늘이 생기는 3루 쪽에 배치된다." — 매일신문 〈[라이온즈파크 톺아보기]<2> 관중 배려한 설계〉(2016-03-15)
  <https://www.imaeil.com/page/view/2016031518243391261>
- 같은 내용이 KBS 뉴스(2015-10-05)와 위키백과 "대구삼성라이온즈파크" 항목에도 있습니다.
- 모델 구현: 경기장 로컬 좌표(센터 필드 = +Y)를 월드 좌표에서 **−67.5°** 회전해 앉혔습니다.
  결과적으로 3루 쪽(홈팀 응원석)이 북북동, 1루 쪽이 남남동을 향하고, 16시 이후 3루 응원석이
  그늘에 드는 배치가 됩니다.

## 2. 펜스 · 스탠드 수치

| 항목 | 수치 | 모델 반영 |
| --- | --- | --- |
| 좌·우 페어폴 | 99.5 m | `fence_radius(±45°)` |
| 좌중·우중 | 123.4 m | `fence_radius(±22.5°)` |
| 중앙 | 122.5 m | `fence_radius(0°)` |
| 펜스 높이 | 3.6 m | `Outfield_Wall` (3.6 m + 상단 캡) |
| 하부 스탠드 ~ 1·3루 베이스 | 18.3 m (국내 최단) | `Field_Box_Wall` (베이스에서 18.3 m) |
| 대지면적 | 151,526.00 ㎡ | `parcel_polygon()` — 정팔각형 면적이 정확히 151,526.00 ㎡ |

- 18.3 m 근거: 매일신문 같은 기사 "하부 스탠드에서 1, 3루 베이스까지의 거리는 18.3m로 국내 최단거리다."
- 지적면적은 브리프에 제시된 공식 대지면적 151,526.00 ㎡를 그대로 사용했습니다. 정팔각형 한 변
  `a = √(A / (2(1+√2))) ≈ 177.2 m`, 외접반경 `r ≈ 231.5 m`이며, `lionspark-cadastre.json`에
  꼭짓점 좌표가 들어 있습니다.

## 5. 좌표계

- Blender: 미터, Z-up, **+Y = 진북**, +X = 동.
- 웹(Three.js)은 `(x, z, −y)`로 받습니다. 즉 **−Z = 진북**.
- `public/models/lionspark-cadastre.json`의 `parcelPolygon`은 웹 좌표 `[x, z]`입니다.
- 앱의 태양 위치(`src/features/lionspark/astronomy.ts`)도 같은 규약을 쓰므로, 모델을 다른
  방위로 돌리면 그늘 고증이 어긋납니다.

## 6. 재현

```sh
python3 scripts/prepare-v6-graphics.py          # WIN OR WOW·혼연일체·스폰서·마스코트·지적도 텍스처
blender --background --python assets/blender/lionspark_v6_build.py
```

산출물: `public/models/lionspark.glb`, `lionspark-collision.json`, `lionspark-scene.json`,
`lionspark-cadastre.json`, `assets/blender/lionspark-v6.blend`, `assets/blender/v6-manifest.json`,
`assets/blender/references/*.png`.

## 7. 해석의 한계

- 스폰서 광고판과 마스코트는 **글자와 단순 도형으로 다시 그린 재현물**입니다. 실제 구단·기업의
  로고 파일을 복제하지 않았습니다.
- 전광판의 스코어(팀·이닝·타자·투수)는 레이아웃을 보여 주기 위한 예시 값입니다.
- 지적 경계는 공식 대지면적 151,526.00 ㎡를 만족하는 정팔각형으로 단순화한 것이며, 실제
  필지 경계선의 측량 좌표가 아닙니다.
