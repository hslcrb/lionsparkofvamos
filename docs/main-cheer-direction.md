# 메인 응원 문구 기획

- 첫 화면은 구단 응원가 ‘드림오브라이온즈’에서 확인한 구호를 이사만루 Bold로 배치한다.
- 구분 띠에는 ‘승리가’와 ‘엘리제를위하여’에서 확인한 짧은 응원을 쓰고, 마지막에는 ‘2012 라이온즈 승리가’의 구호로 마무리한다.
- 응원 수와 응원관에는 기능 설명만 남긴다. 실제 경기 결과를 암시하는 문구나 설명을 위한 장식 문장은 넣지 않는다.
- 기존 삼성 블루와 로고를 유지하며 모바일에서도 구호를 읽고 응원 버튼과 응원관을 사용할 수 있어야 한다.
